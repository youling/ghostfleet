连接 Tailscale 纳管权限

GhostFleet 使用一个最小权限 OAuth Client，为每台新设备临时生成一次性纳管凭据。

  1. 在 Tailscale 创建 OAuth Client

    打开 Trust credentials，选择 Credential → OAuth。

    打开 Tailscale
  2. 只授予纳管所需权限

    在权限列表找到 Keys → Auth Keys，选择 Write；标签只选 tag:fleet-ssh-target。若标签不存在，请先在 Tailscale 访问策略中创建。

    Scope
    auth_keys
    设备标签
    tag:fleet-ssh-target

    不要授予 devices、DNS、ACL 或 tailnet admin 等额外权限。

  3. 创建后回到这里

    Tailscale 只会显示 Client Secret 一次。下一步将由 GhostFleet 安全验证并交给私有 authority service 托管。

    此凭据只用于当前验证请求，不写入浏览器存储或 GhostFleet 生命周期状态。
