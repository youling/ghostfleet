# Third-party components

GhostFleet does not bundle or redistribute the following runtime components. Install them from their official distribution channels and follow their own licenses and terms:

- Cloudflare `cloudflared` / Cloudflare Tunnel / Cloudflare Access
- Tailscale `tailscaled` / `tailscale`
- OpenSSH client and server
- systemd and systemd-journald

GhostFleet contains only generic configuration examples and documentation. It does not embed third-party binaries, private credentials or provider SDKs.
